# Motion Reel ’26

A 15-second, 1080p60 motion-design showreel in which **every frame and every sound is generated by code**.
There's no After Effects, no stock footage and no samples: a Canvas2D and WebGL2 renderer, a numpy synth, and ffmpeg.

## How it works

- **Pure functions of time.** Each scene is a `draw(ctx, t)` with no hidden state, so frames render in any order on any worker. This is also why the montage can "re-shoot" earlier scenes: it just calls them with an old `t`.
- **Real motion blur.** Every output frame is 8 sub-frames across a 180° shutter, accumulated in a half-float WebGL2 target and resolved with dither. That's 7,200 sub-frames in total.
- **A lens pass** (`src/gl.js`) adds impact-driven chromatic aberration, barrel warp, flash, vignette, per-frame film grain (PCG hash), and the liquid layer plus its refraction.
- **Camera energy.** A single impact envelope drives shake, zoom punch and lens warp, so every hit reads in both picture and sound.
- **Everything on the grid.** The piece runs at 120 BPM, and cuts land on beats and on exact frame boundaries. The shutter leads each frame, so no frame straddles a cut.
- **Score** (`tools/soundtrack.py`). Oscillators and filtered noise only: kicks, claps and hats, a sidechained bass and pad in A minor, risers, whooshes, plucks, bells and a glass shatter. Each sound is placed at the timestamp of its visual event.

## Build

```bash
npm install                                     # playwright (uses the preinstalled Chromium)
pip install numpy scipy imageio-ffmpeg          # synth + an ffmpeg with libx264
export FFMPEG=$(python3 -c "import imageio_ffmpeg as i; print(i.get_ffmpeg_exe())")

python3 tools/soundtrack.py                      # → out/soundtrack.wav
node tools/render.mjs --workers 4 --samples 8   # → out/reel_silent.mp4
$FFMPEG -i out/reel_silent.mp4 -i out/soundtrack.wav -c:v copy -c:a aac -b:a 256k -shortest out/showreel.mp4
```

For a live, scrubbable preview (space to play, ←/→ to step), open `src/index.html` through any static server.
Use `node tools/render.mjs --stills 2.1,6.5,14.3` to write QA stills to `out/stills/`.
